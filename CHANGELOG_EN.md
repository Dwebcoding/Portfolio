# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2026-01-15

### Added
- Complete internationalization system (Italian/English)
- Terminal-style interface with typewriter effects
- Mobile optimization with responsive breakpoints
- Performance optimizations with lazy loading
- Legal pages (Privacy Policy, Terms of Service)
- Social media integration (GitHub, LinkedIn, WhatsApp)
- Contact form with client-side validation
- Mobile testing suite
- Accessibility improvements

### Changed
- Redesigned with GitHub-inspired dark theme
- Improved project showcase with screenshots
- Enhanced navigation with language switcher
- Optimized CSS architecture with modular approach
- Updated JavaScript to ES6+ with async/await

### Technical Improvements
- Modular JavaScript architecture
- CSS custom properties for theming
- Optimized animations with `will-change`
- Reduced motion support for accessibility
- Performance metrics tracking
- SEO optimization

### Dependencies
- Bootstrap 5.3.3
- AOS 2.3.1
- Font Awesome 6.5.1
- JetBrains Mono font

## [1.0.0] - 2025-12-01

### Added
- Initial portfolio structure
- Basic HTML pages
- CSS styling
- JavaScript functionality
- Project showcase
- Contact information
