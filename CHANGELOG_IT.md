# Changelog

Tutte le modifiche significative a questo progetto saranno documentate in questo file.

Il formato è basato su [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
e questo progetto aderisce al [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2026-01-15

### Aggiunto
- Sistema di internazionalizzazione completo (Italiano/Inglese)
- Interfaccia in stile terminale con effetti macchina da scrivere
- Ottimizzazione mobile con breakpoint responsive
- Ottimizzazioni delle prestazioni con lazy loading
- Pagine legali (Privacy Policy, Termini di Servizio)
- Integrazione social media (GitHub, LinkedIn, WhatsApp)
- Form di contatto con validazione client-side
- Suite di test mobile
- Miglioramenti di accessibilità

### Modificato
- Ridisegnato con tema scuro ispirato a GitHub
- Migliorata la vetrina progetti con screenshot
- Navigazione migliorata con selettore lingua
- Architettura CSS ottimizzata con approccio modulare
- JavaScript aggiornato a ES6+ con async/await

### Miglioramenti Tecnici
- Architettura JavaScript modulare
- Proprietà CSS personalizzate per il theming
- Animazioni ottimizzate con `will-change`
- Supporto per riduzione movimento per accessibilità
- Tracciamento metriche prestazioni
- Ottimizzazione SEO

### Dipendenze
- Bootstrap 5.3.3
- AOS 2.3.1
- Font Awesome 6.5.1
- Font JetBrains Mono

- Struttura portfolio iniziale
