# Contribuire al Portfolio

Grazie per il tuo interesse nel contribuire a questo progetto portfolio! Ecco alcune linee guida per aiutarti a iniziare.

## Come Contribuire

### Segnalazione Problemi
- Usa il sistema di issue di GitHub per segnalare bug
- Fornisci informazioni dettagliate sul problema
- Includi i passaggi per riprodurre il problema
- Menziona il tuo browser e sistema operativo

### Suggerire Miglioramenti
- Apri un issue con l'etichetta "enhancement"
- Descrivi la funzionalità che vorresti vedere
- Spiega perché sarebbe utile
- Considera l'ambito e gli obiettivi del progetto

### Contributi al Codice

1. **Fai un fork del repository**
2. **Crea un branch per la funzionalità**
   ```bash
   git checkout -b feature/nome-tua-funzionalità
   ```
3. **Apporta le tue modifiche**
   - Segui lo stile di codice esistente
   - Testa accuratamente le tue modifiche
   - Aggiorna la documentazione se necessario
4. **Committa le tue modifiche**
   ```bash
   git commit -m "Add: breve descrizione delle tue modifiche"
   ```
5. **Push al tuo fork**
   ```bash
   git push origin feature/nome-tua-funzionalità
   ```
6. **Apri una Pull Request**

## Linee Guida per lo Stile del Codice

### HTML
- Usa elementi HTML5 semantici
- Includi etichette ARIA appropriate per l'accessibilità
- Usa attributi data per l'i18n (`data-i18n`)

### CSS
- Segui le convenzioni di denominazione esistenti
- Usa proprietà CSS personalizzate per il theming
- Mantieni i principi del design responsive
- Testa su diverse dimensioni dello schermo

### JavaScript
- Usa funzionalità ES6+
- Segui l'architettura modulare
- Includi commenti JSDoc per le funzioni
- Gestisci gli errori con eleganza

## Testing

- Testa su più browser (Chrome, Firefox, Safari, Edge)
- Verifica il design responsive su diverse dimensioni dello schermo
- Controlla l'accessibilità con screen reader
- Valida HTML e CSS

## Documentazione

- Aggiorna README.md se aggiungi nuove funzionalità
- Documenta eventuali nuove opzioni di configurazione
- Includi commenti nel codice per la logica complessa

## Domande?

Sentiti libero di aprire un issue se hai domande sui contributi!
